🎬 MovieVerse - Dynamic Movie Showcase Website
Welcome to MovieVerse, a responsive and visually immersive movie browsing web app. 
Built using the modern web development stack (HTML, CSS, and Vanilla JavaScript), 
this project mimics the front-end of a movie streaming platform like Netflix or Hotstar, offering a clean UI, responsive layout, and smooth user interaction.

🚀 Overview
This project is a fully responsive front-end movie website that highlights featured content,
categorized movie sections, and user navigation—all crafted without using any front-end frameworks like React or Vue.
It's ideal for learning layout structuring, DOM manipulation, and UI/UX design in plain JavaScript.

🚀 Live Demo
Experience the live version of the project here: https://movie-website-rosy-sigma.vercel.app/

🖥️ UI Preview

The homepage features:

A hero section with a featured movie and an interactive “Watch” button.

Multiple scrollable sections with categorized movie thumbnails (e.g., “New Hindi Movies”).

A fixed sidebar menu for navigation with iconography.

A dark mode toggle in the navbar (for better UX).
